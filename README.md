## Sobre o Projeto

O OrbitEye é uma aplicação web desenvolvida para demonstrar como tecnologias da Indústria Espacial podem auxiliar no monitoramento climático e na prevenção de desastres naturais.

A solução utiliza o conceito de monitoramento por satélites para identificar riscos ambientais, fornecer informações em tempo real e auxiliar autoridades e comunidades na tomada de decisões.

---

## Funcionalidades

- Landing Page responsiva
- Slideshow imagens relacionadas ao tema
- Sistema de troca de temas 
- Formulário com validação de campos utilizando JavaScript
- Quiz dinâmico com 10 perguntas sobre o projeto
- Exibição automática do resultado final do quiz
- Interface desenvolvida com HTML, CSS e JavaScript puro

## Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/pedrin3a/GS-WEB-DEV
```

2. Entre na pasta do projeto:

```bash
cd GS-WEB-DEV
```

3. Abra o arquivo `index.html` em qualquer navegador.

Não é necessário instalar bibliotecas ou frameworks.

---

## Objetivo

Demonstrar como tecnologias inspiradas na Indústria Espacial podem ser utilizadas para monitoramento climático, prevenção de desastres naturais e apoio à tomada de decisões por meio de dados coletados por satélites.
